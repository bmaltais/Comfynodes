## 2025-05-14 - Device Mismatch in Hybrid Nodes **Learning:** When implementing ComfyUI nodes that use NumPy/OpenCV (CPU) for processing, the resulting tensor must be explicitly moved back to the original device (e.g., GPU) to avoid runtime errors during subsequent PyTorch operations like blending. **Action:** Always use `.to(original_tensor.device)` when converting from NumPy back to Torch tensors.
